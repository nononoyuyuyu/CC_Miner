タートルの詳しい置き方

基本の建築はブロックを置くだけで完成します。このページは、装備や各チェストの役目、補給から採掘へ戻る流れを詳しく確認したいときに使います。

タートル本体に付ける装備

装備付ける側必要な理由
もともと付いているピッケル右側のまま前・上・下のブロックを掘るために必要です。
無線モデム左側へ追加管理用コンピューターから指示を受け、状態を返します。

装備欄の左右と、タートルの周りに置く「左面・右面」は別のものです。ここでいうピッケルとモデムは、タートル本体の装備欄です。

左側へ無線モデムを装備する

  1. 無線モデムを持たせる

    タートルの持ち物を開き、左上の1番の枠へ無線モデムを1個入れます。

  2. Lua入力画面を開く

    lua

  3. 1番の枠を選ぶ

    turtle.select(1)

    true と表示されます。

  4. 左側へ付ける

    turtle.equipLeft()

    true と表示されれば装備できました。

  5. モデムか確認する

    peripheral.getType("left")

    modem と表示されることを確認します。

  6. Lua入力画面を閉じる

    CtrlとTを長押しします。通常の入力画面へ戻ったら、右側のピッケルを外していないことも確認します。

空の持ち物枠を選んだまま turtle.equipLeft() を実行しないでください。左側に別の装備がある場合、その装備を外す操作になります。必ず1番の枠に無線モデムが見えている状態で実行します。

チェストの位置

採掘タートルの周囲

上面燃料チェスト
左面たいまつチェスト
正面採掘口・空ける
右面穴埋め材チェスト
背面搬出チェスト
底面床

上面は燃料、左面はたいまつ、右面は穴埋め材、背面は搬出です。正面は採掘口なので空け、底面は床にします。

燃料チェスト

石炭など、タートルが燃料にできる物だけを入れます。燃料にできない物を入れても補給できません。

たいまつチェスト

設定で許可したたいまつだけを入れます。たいまつ機能をOFFにするなら、なくても構いません。

穴埋め材チェスト

水や溶岩をふさぐ固いブロックを入れます。掘った石の再利用もできます。

搬出チェスト

掘った物を出す場所です。満杯になると採掘を再開できません。

帰還と再開地点

タートルは、荷物がいっぱいになる前や燃料が少なくなる前に、掘っていた場所を「再開地点」として保存します。そのあと安全な通路を通って自分の置き場へ戻ります。

帰還と再開の流れ

1. 採掘場所今いる場所と向きを保存
2. 自分の置き場搬出・燃料・資材を補給
3. 再開地点保存した場所と向きを確かめて続行
安全確認した通路を往復します

採掘場所で再開地点を保存し、自分の置き場へ戻って補給します。その後、保存した場所へ戻り、位置と向きを確認してから採掘を続けます。

以前のように範囲の一番奥まで行って折り返す必要はありません。保存した再開地点まで、許可されたチャンクの最短経路を使って戻ります。

たいまつの置き方

タートルは通路の左右を調べ、安全に置ける側へたいまつ用の小さなくぼみを作ります。チェスト、液体、砂や砂利、保護するブロックは掘りません。両側とも安全でない場合は、勝手に壊さず停止します。

掘った石の再利用

石を一定数だけ持ち、穴埋め材として先に使います。持ち過ぎた石は、設定によって搬出するか、その場で捨てます。鉱石、燃料、たいまつ、穴埋め用に残す分は守られます。

タートルを増やす前に

1台ずつに、専用の置き場とチェストが必要です。同じチェストや入口を共有すると衝突します。増やす手順は複数台を使うへ進んでください。
