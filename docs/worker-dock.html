ワーカー装備とドック設計

ドックはワーカーが必ず帰還でき、搬出・燃料・seal 材・torch を安全に補給できるホームです。1 bay を確実に作ってから、必要なら同じ寸法で複数 bay を増設します。

テキスト代替：タートルの後ろが搬出、真上が燃料、右が seal、左が torch。モデムは worker と controller の遠隔通信に使います。

  • Wireless Modem は worker ごとに 1。controller も Wireless Modem が必要です。
  • 搬出チェストは空きを確保し、燃料チェストに燃料以外を混ぜません。
  • seal 材候補は Cobblestone、Cobbled Deepslate、Stone、Netherrack、Dirt など、設定した許可リストだけです。
  • 砂・砂利・TNT・バケツ・可燃物・液体・貴重ブロックを seal 材に登録しません。
  • 採掘石の再利用を有効にすると、許可名と一致する固体だけを予約 slot に保持します。上限超過分は搬出または待機です。

テキスト代替：管理 dock は共有しても、A と B は一意な bay chunk、チェスト、worker、mine/transit assignment を共有しません。各 bay は独自の home pose、GPS CAL、帰還経路を持ちます。

分割の境界。 通常の単一 job は 1 footprint を複数 worker へ自動分割しません。複数 worker を並列運転する場合は、own bay chunk と X/Z が重ならない独立 job を worker ごとに queue します。world group job を明示した場合だけ、preflight 済みの partition、own assignment、lease に従って分割します。local 座標の bay 間重複は自動判定できません。

経路と帰還

除外なしは通常の serpentine、除外ありの採掘実行順は許可 chunk の復旧可能な DFS walk です。補給・帰還の chunk path は shortestServiceRoute だけが BFS で求め、現在位置から worker map に対応する own bay/dock chunk へ戻ります。補給後は自分の dock/home から checkpoint へ同じ許可辺を通って復帰し、GPS と向きを検証して walk を再開します。

テキスト代替：C3 から shortestServiceRoute の BFS で worker 固有の bay/dock へ戻り、搬出・補給後に同じ BFS helper で保存した checkpoint C3 へ戻って向きを検証します。採掘順そのものは DFS walk です。

設置後チェックリスト

  1. タートルの正面と GPS CAL 用の往復スペースが空いている。
  2. 搬出に空き、燃料に燃料、seal と反対側の専用 torch に許可アイテムがある。
  3. reserved slot と seal/torch 保持上限が重ならない。
  4. worker/controller の Wireless Modem と network key が一致する。
  5. 小さい job の preflight、照明、液体、帰還を試験する。

dock / bay と worker map の登録

物理配置を作ったら、controller の端末で 1 つの管理 dock と worker ごとの bay を整数ワールド座標で登録します。dock は複数チャンクにまたがる管理アンカー、bay は own assignment の帰還入口です。facing は front/south=0、right/east=1、back/north=2、left/west=3、または 0〜3。最後の maxDepth は正の整数です。

ccm dock register dock-a 100 64 100 east 64
ccm bay register bay-a 100 64 100 east 64
ccm bay register bay-b 116 64 100 east 64
ccm group register quarry-a 101,102 QuarryA dock-a bay-a world stripe 101=bay-a,102=bay-b 101=dock-a,102=dock-a

最後の 2 引数がそれぞれ workerBays と workerDocks の map です。書式は workerId=resourceId,...（空白なし）。map のキーは group に登録した worker だけにし、値は登録済み bay / dock ID と一致させます。ccm dock list、ccm bay list、ccm group show quarry-a で保存値を確認してください。

world group の preflight 制約。 各 worker の home と正面 1 ブロック先は同じ自分の bay chunk、worker 間 bay chunk は一意、全 bay chunk は job footprint 内でなければなりません。GPS の dimension・HOME Y（same floor）・forward orientation も一致させ、own assignment の mine/transit lease と帰還経路を分離します。bay chunk の重複、footprint 外、floor / facing 違反は fatal。例の x=100 と x=116 は別 chunk です。詳細は group 登録と preflight を参照してください。
