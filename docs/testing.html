マニュアル / 検証

P1 / release check

静的検査と実機受入試験

リリース確認では Python 3.10 以降と Lua 5.2 互換の texlua、lua5.2、lua のいずれかを用意します。Lua が無い場合、非 Lua 検査だけが走り、全検証完了とはみなしません。

検査コマンド

python tools/check.py
python tools/build_offline_bundle.py

CCMINER_LUA に互換 Lua のパスを設定できます。bundle の差分を指摘された場合は、先に build を実行してから check を再実行します。

実機受入試験（小さく始める）

job と grid

  • 小さい寸法で preflight OK。
  • stock warning と fatal 拒否。
  • ALL/CLEAR/個別/RECT/INVERT、入口固定、分断拒否。
  • world targetY と local depth の違い。

profile と group

  • SAFE（torch 8、fuel 1.5x、seal 8）、BALANCED（10/32）、TURBO（12/64）。
  • world group partition、共通 BOTTOM Y、stagger、PARTIAL_START、REASSIGN。
  • local group の自動分割拒否。

素材・照明

  • seal=右／torch=左、niche、保護 block 回避。
  • 両側不可の安全停止、floor fallback 非致命。
  • seal 再利用上限、discard allowlist。unknown mod item は既定／stone mode で保持し、CUSTOM は正確な完全 item ID の明示時だけ候補。

停止・通知

  • 即時／行末／層末／帰還／中止。
  • 補給中の電源断→再ロード checkpoint。
  • speaker/redstone、仕分け満杯 retry、waiting_output 非直結。

実機環境の注意

  1. バックアップしたワールドと小さな保護区画を使用。
  2. GPS host と採掘地点の chunk load をサーバー管理者が用意。CC Miner の結果と混同しない。
  3. 未知の Mod block/fluid は protected list と試験 job で明示。
  4. テスト後に report、logs、state.db／.bak、journal を保存。
このページ自体は検査を実行しません。 実行環境と承認済みの試験ワールドを用意してから、担当者がコマンドを実行してください。
