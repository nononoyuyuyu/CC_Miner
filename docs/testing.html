手順書 / 動作確認

動作確認

大きな採掘を始める前に、小さな範囲で1つずつ確認します。すべて同時に試すと、止まった原因が分かりにくくなります。

設置した人が行う確認

  1. 接続

    再起動後に管理画面へ採掘タートルが表示される。

  2. 小さな採掘

    幅16、長さ16、深さ8、照明OFF、水・溶岩STOPで完了できる。

  3. 搬出

    背面のチェストへ掘った物を出し、満杯なら安全に待機する。

  4. 燃料

    上面チェストから補給し、燃料がなければ安全に待機する。

  5. 帰還と再開

    途中でRETURN HOMEを指示し、補給後に保存した場所へ戻って続ける。

  6. たいまつ

    小さな安全な範囲でONにし、左右の安全を確認して設置する。

  7. 水・溶岩

    まずSTOPを確認し、その後に穴埋め材を十分用意してSEALを少量で試す。

  8. GPS

    4台を起動し、GPS CAL後に現在位置と一番下の高さが正しく表示される。

更新後に確認すること

  • 設定が残っている
  • 採掘途中なら状態と再開地点が残っている
  • 管理用コンピューターが採掘タートルを見つける
  • 新しい作業を作る前に、前の作業の状態が正しい

開発者向けの自動確認

この項目だけは、リポジトリを変更する人向けです。通常の利用者は実行しなくて構いません。

すべての検査

python tools/check.py

オフライン配布物だけ作り直す

python tools/build_offline_bundle.py

すべて成功すると All CC Miner V4 checks passed. と表示されます。Luaの実行環境がない場合は、成功したとは扱いません。
