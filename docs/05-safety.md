# 05. 安全設計

## 除外チャンクへ侵入しない条件

チャンク除外ジョブは、許可チャンクだけで構成した隣接グラフを作ります。入口チャンクを根としたDFSで全許可チャンクへ到達できる場合だけ開始します。

- 採掘: 各許可チャンク内部だけを蛇行
- チャンク間移動: 隣接する親子アンカー間だけ
- 補給帰還: 現在チャンクからDFS親をたどって入口へ戻る
- 作業復帰: 入口から親経路を逆順にたどる

したがって、採掘中だけでなく補給・帰還中も除外チャンクへ入りません。

## 溶岩

封鎖材は必ず固体・非重力・非燃焼の安価なブロックを使います。砂・砂利・TNT・バケツ・可燃ブロックは登録しないでください。

`turtle.place*` が失敗した場合、溶岩へ移動せず停止します。溶岩名を含むMod追加流体にも保守的に反応しますが、特殊流体の挙動は実環境で確認してください。

## GPS

GPSは位置を測れますが向きは直接測れません。このため、電源断中の前進・上下移動は操作前後の位置と比較して解決できますが、旋回中の電源断は自動解決しません。

GPSを必須にすると、fixを取得できない状態では採掘を開始・継続しません。任意モードではGPS障害時もローカル座標で継続します。

## 保護ブロックとインベントリ

Bedrock、End Portal、End Portal Frame、Nether Portal、Reinforced Deepslate、Computer/Turtle類を保護対象にしています。進行方向のチェスト、樽、Shulker Boxなどのインベントリも掘削しません。

Mod追加の重要ブロックは `protectedBlocks` へ追加してください。

## 燃料と在庫

補給判断は、通常ジョブではドックまでのマンハッタン距離、チャンク除外ジョブでは現在位置から入口までのDFS親経路を使って帰還距離を見積もり、`fuelBuffer` を加えます。ドックでの補給目標も作業地点との往復距離を下回らないよう補正します。掘削不能ブロックの迂回は行わないため、Mod追加環境では余裕を持った `fuelBuffer` と `fuelTarget` を設定してください。

搬出時は封鎖材を保持し、それ以外を搬出します。搬出チェスト満杯、燃料切れ、封鎖材チェスト空、異物混入はそれぞれ待機状態として表示します。

## 手動移動

稼働中のタートルをピストン、レンチ、プレイヤー操作で移動・回転させないでください。GPS不一致を検出した場合は安全停止します。物理回収後はドックへ戻し、正面を合わせてREHOMEします。
