マニュアル / 日常操作

P0 / 5 分で job

ジョブを作り、止め、再開する

最初は BALANCED の小さい範囲で、入口と帰還を確認します。profile の安全値を下げる設定はありません。明示した waterMode と lighting.mode は profile で上書きされません。

SAFE / BALANCED / TURBO

profile実効値使いどころ
SAFE空き slot 設定値 +2、fuel margin 1.5 倍、torch 間隔最大 8、stack 整理最大 16 moves、continuous seal cap 8（worker 絶対上限との小さい方）。初回、未知の Modpack、長い帰還。時間・補給は増える。
BALANCED既定 torch 10、compact 32、continuous seal cap 32。fuel safety は設定値。通常運転と受入試験の開始点。
TURBO空き slot 設定値 -1（最低1）、fuel safety は下げない、torch 12、stack 整理 64 moves、continuous seal cap 64（絶対上限との小さい方）。実績を確認した範囲。worker 絶対上限を超えない。

chunk grid と除外

1 タイル = 1 chunk。部分セルはなく、入口 chunk は常に採掘対象です。ここでいう「除外」は採掘計画から外す chunk のことで、在庫を捨てる discard ポリシーとは別です。除外 chunk へ採掘・補給・帰還で入りません。

テキスト代替：入口は黄色で固定。緑が採掘対象、灰が除外、青が済み、橙が現在または停止。色だけに依存せずラベルも表示します。

  1. 初期状態または ALL は全 chunk を採掘対象。
  2. CLEAR は入口以外を解除。
  3. 個別タッチで 1 tile を切替。
  4. RECT は二点を選び、その矩形だけを対象。
  5. INVERT は入口を固定したまま反転。

入口除外、許可 chunk の分断、world active／queued の重複は START／QUEUE で拒否されます。

preflight と見積の読み方

表示扱い対処
offline / invalidfatal接続、寸法、worker ID、設定形式を直す。
connectivityfatal入口から連結するよう grid を選び直す。
capability / leasefatalworker capability と active job を確認。
gps_required / overlapfatal4 host・CAL、または X/Z の重複を解消。
fuel / stock / seal / torchwarning補給前提でチェストと reserved slot を用意。

見積は採掘セル、体積、移動・旋回、想定補給、燃料、seal、torch を示します。液体分岐、保護 block、Mod 追加の迂回、仕分け待ちは実績に含まれない場合があります。

queue と group

world queue は GPS world の X/Z 範囲を比較し、active／queued と重なる job を拒否します。local queue は指定 worker 内の登録順だけを保証します。通常の複数 worker 運用は 非重複な独立 job を各 worker に登録し、dashboard 稼働中に dispatch します。1 footprint の自動分割は通常 job では安全上無効です。

world group job は例外で、登録済み group の worker へ共通 footprint を preflight 済みの chunk assignment として partition します。group 名だけで lease／重複検査を省略できず、local group の自動分割は行いません。

段階停止

即時

現在の物理操作を安全に確定した境界で停止。

行末

現在の serpentine 行を終えて停止。

層末

現在層を終えて停止。

帰還

搬出・補給後、job を保持して home で停止。

中止

帰還・補給後に ABORT し report を保存。

unloading／waiting_* 中に電源断しても、境界・inventory・checkpoint を保存し、次回 load で再検証します。外部 inventory の二重処理は保証しません。
