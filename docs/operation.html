手順書 / 採掘する

採掘する

ここでは、1台の採掘タートルに作業を頼む手順を説明します。最初は幅16、長さ16、深さ8で試してください。

始める前に見るもの

  • 採掘タートルが置き場にいて、正面を向いている
  • 正面に人、動物、チェスト、壁がない
  • 上面の燃料チェストに燃料がある
  • 背面の搬出チェストに空きがある
  • 管理画面に採掘タートルの番号が表示される

新しい採掘作業を作る

  1. 管理画面を開く

    ccm dashboard

  2. 採掘タートルを選ぶ

    画面の番号をクリックします。クリックできない場合は、矢印キーで選び、Enterを押します。

  3. NEW JOBを選ぶ

    これは「新しい採掘作業」という意味です。

  4. 大きさを入れる

    WIDTHは横幅、LENGTHは前方向の長さ、DEPTHは深さです。最初は16、16、8にします。

  5. 採掘するチャンクを選ぶ

    緑にしたマスを掘ります。入口のマスは安全のため外せません。1つだけ選ぶところから始めます。

入口は固定です。緑のマスは採掘し、灰色のマスは採掘しません。青は現在作業中のマスです。

画面の文字やること
ALLすべてのマスを採掘する
CLEAR入口以外をすべて「掘らない」にする
INVERT「掘る」と「掘らない」を入れ替える
RECT最初の角と反対側の角を押し、四角い範囲をまとめて選ぶ

開始前チェック

PREFLIGHTは「開始前チェック」です。ここで問題があれば、まだタートルは動きません。

緑：開始できます

接続、範囲、設定に問題がありません。

黄：注意があります

燃料やたいまつが少ないなどです。始められる場合もありますが、補給してからがおすすめです。

赤：開始できません

接続、GPS、範囲のつながり、他の作業との重なりなどを直します。

開始と見守り

  1. STARTを押す

    開始前チェックの赤が0件なら押せます。

  2. 最初の数分を見る

    正面へ進む、採掘する、荷物を持つ、表示が更新されることを確認します。

  3. 手で触らない

    停止したように見えても、補給や位置確認をしていることがあります。まず管理画面の状態を読みます。

止めたいとき

画面の文字意味使う場面
PAUSE NOWできるだけ早く一時停止様子を確認したい
FINISH ROW今の横1列を終えて停止きりのよい所で止めたい
FINISH LAYER今の高さを終えて停止長めに待てる
RETURN HOME置き場へ戻る補給や点検をしたい
ABORT作業を中止同じ作業を続けない
ABORTとREHOME RESETは違います。REHOME RESETは位置情報や作業情報を消す強い操作です。普段の中止にはABORTを使います。

補給のために戻ったとき

荷物、燃料、たいまつ、穴埋め材が足りなくなる前に置き場へ戻るのは正常です。戻る回数が多すぎる場合は帰還回数を減らすを確認します。

余った物を自動で捨てたい場合は、採掘タートルを置き場へ戻してから、管理画面の MORE → ITEMS を開きます。物の名前をタッチし、APPLYを押します。
