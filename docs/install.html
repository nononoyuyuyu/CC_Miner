プログラムを入れる

先にブロックを置くを終えてください。ここでは、採掘タートル、管理用コンピューター、GPS用コンピューターの順にプログラムを入れます。

最初に合言葉を決める

採掘タートルと管理用コンピューターが、お互いを見分けるための文字です。紙などに控え、すべて同じ文字を入力します。画面では network key と表示されます。

公開しないでください。配信や画面写真に合言葉を写さないでください。また、強い暗号ではないため、信頼できる人だけが入れるゲーム内ネットワークで使ってください。
初回から省容量方式を使います。CCのコンピューターは保存容量が小さいため、最新版はファイルを1個ずつ確認しながら入れます。途中で止まっても、/ccminerや復旧用ファイルを消さず、まったく同じインストールコマンドをもう一度実行してください。

1. 採掘タートルへ入れる

  1. 左側へ無線モデムを装備する

    右側にもともと付いているピッケルは外しません。持ち物の1番へ無線モデムを入れ、Lua入力画面で turtle.select(1) と turtle.equipLeft() を実行します。詳しい手順どおり、左側が modem になったことを確認します。

  2. 次の1行を入力する

    wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua worker

    1行のまま入力し、Enterを押します。

  3. 質問に答える

    初回は SAFE、不要品を捨てない、GPSは使わない、照明OFF、水と溶岩はSTOPがおすすめです。項目の説明は採掘タートルの設定にあります。

  4. 再起動する

    reboot

    起動後、エラーを表示せず待機すれば完了です。

2. 管理用コンピューターへ入れる

  1. 左面の無線モデムを確認する

    起動時から付いている必要があります。あとから付けた場合は再起動します。

  2. 次の1行を入力する

    wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua controller

  3. 同じ合言葉を入れる

    採掘タートルと1文字でも違うと見つかりません。大文字と小文字も同じにします。

  4. 再起動し、管理画面を開く

    reboot
ccm dashboard

    採掘タートルの番号が表示されれば成功です。

3. GPSを使う場合だけ入れる

4台すべてに同じGPS用プログラムを入れます。

wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua gps

  1. 各モデムの座標を入力する

    GPS用コンピューター本体ではなく、隣の無線モデムのX・Y・Zを入れます。

  2. 4台を起動したままにする

    再起動後、GPSとして待機している表示を確認します。

  3. 採掘タートルを校正する

    置き場の正面を空けます。管理画面で採掘タートルを選び、GPS CALを押します。正面へ1マス進んで戻れば成功です。

通信できない場合

別のPCから、役割に合ったファイルと同名の部品フォルダーをセットで移します。初めての方は、ファイル名の worker、controller、gps を取り違えないでください。

ccminer-offline-worker.lua      と ccminer-offline-worker.parts
ccminer-offline-controller.lua  と ccminer-offline-controller.parts
ccminer-offline-gps.lua         と ccminer-offline-gps.parts

採掘タートルでは ccminer-offline-worker.lua、管理用コンピューターでは ccminer-offline-controller.lua を実行します。成功すると、容量を空けるため部品フォルダーは削除されます。元のファイルは別のPCへ残してください。

更新する

通常の更新

wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua update

「空き容量がない」「バックアップできない」と表示されたときは、古いフォルダーを手で消さず、次を使います。

空き容量が少ないとき

wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua update-low-space

最新版の通常更新は、一時コピーを書き切れないとき、省容量更新へ自動で切り替わります。Regular staging does not fit と表示された後、そのまま処理が続くのは正常です。

更新途中で止まった場合：同じ省容量更新コマンドをもう一度実行します。/ccminer.update.low-space.marker や /ccminer を手で削除しないでください。

入れ終わったら確認する

  • 採掘タートルと管理用コンピューターを再起動した
  • 両方の無線モデムが起動時から付いている
  • 両方へ同じ合言葉を入れた
  • ccm dashboard に採掘タートルの番号が出る
  • GPSを使う場合は4台が待機中で、GPS CALが成功した
