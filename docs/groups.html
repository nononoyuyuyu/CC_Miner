手順書 / 複数台を使う

複数の採掘タートルを使う

1台で採掘、帰還、補給、再開が成功してから増やしてください。複数台では、管理用コンピューターは共用できますが、タートルの置き場とチェストは1台ずつ分けます。

守ること

  • すべての採掘タートルでGPSを使い、校正を終える
  • 1台ずつ別の置き場を作る
  • 燃料、搬出、たいまつ、穴埋め材のチェストを共有しない
  • 各タートルの正面を同じ向きにする
  • 置き場の高さを同じにする
  • 置き場同士を最低4ブロック、できれば1チャンク以上離す

1台分の置き場

すべてのタートルで、同じ面配置を使います。AとBのチェストを入れ替えないでください。

各タートルに1組ずつ作る

上面このタートル専用の燃料
左面このタートル専用のたいまつ
正面このタートルの採掘口
右面このタートル専用の穴埋め材
背面このタートル専用の搬出
底面同じ高さの床

複数台でも、上面、左面、正面、右面、背面、底面の配置は1台のときと同じです。チェストはタートルごとに専用です。

置き場とまとめ操作を登録する

モニターから簡単に作る

  1. 全ワーカーでGPS CALを終える

    グループ採掘では各ワーカーの絶対位置が必要です。

  2. WORKERS → GROUPを押す

    一覧の表示がGROUP SELECTへ変わります。

  3. 2台以上をタッチする

    選んだ行は黄色になり、先頭にXが付きます。PREVとNEXTで別ページのワーカーも追加できます。

  4. CREATEを押す

    Group 1、Group 2のような名前で作られます。各ワーカーのGPS情報から専用ドックとベイも登録します。

  5. STARTで範囲を決める

    作成後はGROUPS画面へ移ります。STARTを押し、採掘範囲を入力します。

GPSなしでは作成できません：1台だけの通常採掘にはGPSは不要ですが、複数台で範囲を安全に分けるグループ採掘にはGPS校正が必要です。

次の例では、採掘タートルの番号が101と102です。座標や番号は自分のものへ置き換えます。コマンドが長いため、まず1行ずつ登録して確認します。

全体を管理する場所を登録

ccm dock register dock-a 100 64 100 east 64

タートル101の置き場を登録

ccm bay register bay-a 100 64 100 east 64

タートル102の置き場を登録

ccm bay register bay-b 116 64 100 east 64

2台を1つのまとめ操作に登録

ccm group register quarry-a 101,102 QuarryA dock-a bay-a world stripe 101=bay-a,102=bay-b 101=dock-a,102=dock-a
例の文字意味
dock-a全体を管理する場所の名前。自分で決められます。
bay-a / bay-b各タートルの置き場の名前。
100 64 100X、Y、Zの順のワールド座標。
eastタートルの正面方向。
64安全のために許す最大の深さ。
101,102採掘タートルの番号。空白を入れません。

登録を確認する

ccm dock list
ccm bay list
ccm group list
ccm group show quarry-a

番号、座標、向き、どのタートルがどの置き場を使うかを読み上げて確認します。

まとめて採掘を始める

  1. 全台を置き場へ戻す

    待機中または完了状態にし、GPSの位置が正しいことを確認します。

  2. まとめ操作を選ぶ

    管理画面の GROUPS から登録した名前を選びます。

  3. 範囲を決める

    各タートルの置き場を含むワールド範囲と、一番下の高さを入れます。

  4. 開始前チェックを読む

    置き場の重なり、向き、高さ、GPS、採掘範囲の分け方がすべて緑になるまで開始しません。

  5. 1台ずつ開始されるのを見る

    全台へ同時に送らず、1台の返事を確認してから次の1台へ送ります。途中で失敗した場合は、安全に始められた台だけ停止します。

1台が止まったとき

REASSIGNは、止まったタートルの残りを別のタートルへ引き継ぐ操作です。引き継ぐ側が置き場にいて、GPSと向きが正しく、同じ範囲を掘っていないときだけ使えます。

手でタートルを入れ替えないでください。画面の引き継ぎ操作が終わる前に置き場やタートルを交換すると、同じ場所を二重に掘るおそれがあります。
