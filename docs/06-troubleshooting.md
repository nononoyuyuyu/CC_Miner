# 06. トラブルシューティング

## ワーカーが見つからない

- ワーカーとコントローラーのネットワークキーを一致させる
- 両方のWireless Modemが無線タイプであることを確認
- `ccm discover` を実行
- 通信距離・ディメンション・遮蔽条件を確認
- `ccm logs` でモデム起動エラーを確認

## モニターを触っても反応しない

- Advanced Monitorを使用する
- `ccm setup controller` でタッチ操作を有効にする
- モニターを接続し直すか、コントローラーを再起動する
- 小さいモニターではボタンが圧縮されるため、複数ブロックへ拡張する
- コンピューター本体では `mouse_click` が使えるため、画面をクリックして確認する

## GPS校正に失敗する

- 4台以上のGPSホストが起動している
- ホスト座標が無線モデムブロックの座標になっている
- 4台が同一平面ではなく立体配置されている
- タートル正面1ブロックが空いている
- タートルに2以上の燃料がある
- ドックとGPSホストのチャンクがロードされている

`ccm gps <id>` でfixだけを再確認できます。

## `GPS drift` / `Boot GPS mismatch`

タートルが手動移動されたか、校正後にドックを移設した可能性があります。タートルを元の校正ドックへ戻すか、ジョブを安全に破棄してREHOMEし、GPS CALをやり直します。

## `recovery_required`

電源断時に物理操作が未確定でした。移動・採掘・設置でGPS校正が有効なら起動時に自動解決を試みます。旋回、GPS校正中、fix不能の場合は次の手順です。

1. タートルを物理的にドックへ戻す
2. 採掘方向へ向ける
3. `ccm rehome RESET` またはコントローラーのREHOMEを実行
4. `reboot`

REHOMEは進行中ジョブを消去します。

## `waiting_output`

搬出チェストが無いか満杯です。後ろのチェストと後段物流を確認し、空きを作ってRESUMEします。

## `waiting_fuel`

上の燃料チェストが無い、空、または異物入りです。燃料だけにしてRESUMEします。

## `waiting_seal`

右（設定変更時は左）の封鎖材チェストが無い、空、または許可リスト外のアイテムを含んでいます。Cobblestone等を補充してRESUMEします。

## チャンクマスクを開始できない

- 入口チャンクは除外できません
- 除外した列・帯で採掘対象が分断されていないか確認
- ワールドチャンクモードを使う場合はGPS CALを完了する
- CLEAR MASKで一度全解除し、少数ずつ除外する
