まず動かす：最小構成

このページだけを上から順に進めると、GPSを使わない最小構成で、1台のタートルに小さな範囲を採掘させられます。手順数は少なくしていますが、各手順の確認は省略しないでください。

1. 必要な物をそろえる

  • Advanced Mining Turtle（上級採掘タートル）1台。右側のピッケルは外しません
  • Advanced Computer（上級コンピューター）1台
  • Wireless Modem（無線モデム）2個。タートル用と管理用です
  • チェスト2個。搬出用と燃料用です
  • 石炭など、タートルが使える燃料
  • プログラムを取得できる通信環境
最初の試運転では：たいまつを置かず、水や溶岩を見つけたら停止する設定にします。穴埋め材とたいまつのチェストは、試運転が成功してから追加できます。

2. ブロックを置く

採掘タートルの正面を、これから掘りたい方向へ向けます。周りは、必ず次の形で考えます。

採掘タートルの面と、最小構成で置く物

上面燃料チェスト
左面今は空ける
正面採掘方向・1マス以上空ける
右面今は空ける
背面搬出チェスト
底面動かない床

上面に燃料チェスト、背面に搬出チェストを置きます。正面は採掘方向なので空けます。左右は最初の試運転では空けます。底面には壊れない床を置きます。

タートルの左側へ無線モデムを装備する

  1. タートルの持ち物の1番へ無線モデムを入れます。
  2. タートルの端末で lua と入力します。
  3. 表示されたLua入力画面で、次の3行を1行ずつ入力します。
turtle.select(1)
turtle.equipLeft()
peripheral.getType("left")

2行目が true、最後が modem なら成功です。右側にもともと付いているピッケルは、そのまま残します。確認後は CtrlとTを長押ししてLua入力画面を閉じます。

管理用コンピューターは、タートルから無線が届く場所に置き、左側へ無線モデムを付けます。モニターはなくても動きます。

3. プログラムを入れる

採掘タートルを開き、次の1行を入力します。

採掘タートルで入力

wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua worker

質問には、次のように答えます。

  • 役割：worker
  • 合言葉：自分で決めた文字。あとで管理用コンピューターにも同じ文字を入れます
  • GPS：使わない
  • 動かし方：SAFE
  • 照明：off
  • 水・溶岩：stop
  • 不要品の廃棄：KEEP_ALL

管理用コンピューターを開き、次の1行を入力します。

管理用コンピューターで入力

wget run https://raw.githubusercontent.com/nononoyuyuyu/CC_Miner/main/install.lua controller

合言葉は、採掘タートルと完全に同じ文字にします。大文字と小文字も区別されます。

4. つながったか確認する

  1. 両方を再起動する

    無線モデムを付けた状態で、採掘タートルと管理用コンピューターの両方に reboot と入力します。

  2. 管理画面を開く

    ccm dashboard

    採掘タートルの番号が表示されれば接続成功です。

  3. 見つからない場合

    両方の無線モデム、合言葉、プログラムの版を確認します。詳しくは採掘タートルが見つからないへ進みます。

5. 小さく採掘する

  1. 燃料を入れる

    上面の燃料チェストへ石炭などを多めに入れます。背面の搬出チェストには空きを作ります。

  2. 小さい採掘作業を作る

    管理画面で NEW JOB を選びます。幅16、長さ16、深さ8、照明OFF、水STOP、溶岩STOPを選びます。

  3. 開始前チェックを見る

    PREFLIGHT は「開始前チェック」です。赤い項目が0件であることを確認します。燃料が足りないと表示されたら、燃料を追加します。

  4. 開始する

    START を押します。タートルが正面へ進み、採掘を始めます。動いている間は手で触りません。

  5. 戻るまで待つ

    荷物や燃料のために戻ることがあります。補給が終わると、自分で保存した再開地点まで戻って続けます。

ここまで成功したら：詳しいブロック配置で、たいまつ、穴埋め材、GPSを追加できます。設定の意味は設定を変えるにまとめています。
