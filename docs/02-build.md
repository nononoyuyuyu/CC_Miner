## 事前に選ぶ場所

次の条件を満たす場所を選びます。

- タートル正面から、予定する長さ `L` まで採掘可能
- タートル右側へ、予定する幅 `W` まで他設備と重ならない
- タートルの高さから下へ、予定する深さ `D` まで掘ってよい
- 他人の拠点、配線、Create機械、AE2ケーブル、チェスト、保護領域を横切らない
- タートル、コントローラ、採掘経路のチャンクをロードできる
- 溶岩海、ワールド境界、保護プラグイン領域の近くを避ける

最初に松明や目印で、ホーム、右端、前端を示しておくと向きの間違いを防げます。

## ドックを1ブロックずつ置く

ここでは、採掘方向を「北」と仮定します。実際の方角はどちらでも構いません。

### 1. 搬出チェスト

地面に搬出チェストを1個置きます。このチェストの正面側1ブロックがタートルのホームになります。

搬出チェストを拡張する場合は、まず通常チェストで正しく動く配置を作り、その後にCreate物流へ接続します。タートルが直接向く1ブロックは、汎用インベントリとして認識できる容器にしてください。

### 2. 採掘タートル

搬出チェストの1ブロック前にワーカーを置きます。ワーカーの正面は搬出チェストと反対側、つまり採掘方向へ向けます。

```text
採掘方向 →

[搬出Chest] [Turtle >] [最初に掘るブロック] [2ブロック目] ...
```

正面の三角形やつるはし側だけで判断せず、タートル画面を開く向きと、図の前後を必ず照合してください。

### 3. 燃料チェスト

タートルの真上、1ブロック上へ燃料チェストを置きます。斜め上、横、2ブロック上では動きません。

燃料チェストには有効なタートル燃料だけを入れます。Funnel等で自動投入する場合、フィルタを必ず設定します。

### 4. 前方を確認

タートル正面1ブロック目が採掘範囲の最初です。ここにチェスト、機械、保護したい床、コントローラを置かないでください。

## コントローラを置く

1. Advanced Computerを操作しやすい場所へ置きます。
2. Wireless Modemをコンピュータの上下左右前後のいずれかに直接接触させます。
3. 任意でAdvanced Monitorをコンピュータに直接接触させます。
4. モデムとワーカーの距離をできるだけ短くします。

標準の通常Wireless Modemは、低高度では概ね64ブロック範囲です。Create: Astralやサーバ設定で範囲が変わる可能性があるため、初期構築では16～32ブロック程度に収めると安定します。

## 向きと寸法の具体例

ワーカーが北向きで、`W=8, L=32, D=16` を指定した場合:

- ワーカー正面から北へ32ブロック
- ワーカーから見て右、東へ8列
- ワーカーと同じ高さを第1層として、下へ合計16層
- 総セル数は `8 × 32 × 16 = 4096`

左側は採掘しません。ワーカー中心から左右4ブロックずつではなく、正面から見て右側へ一方向に幅が広がります。

## 採掘範囲の境界を目印にする

誤入力を防ぐため、ジョブ開始前に次を置きます。

- ホーム横に「幅 W」の看板
- 正面端に「長さ L」の一時目印
- 座標メモに開始Yと終了予定Y

目印を採掘体積の内部へ置くと掘られるため、境界の外側へ置きます。

## Create物流を接続する場合

搬出チェストの底面または側面から、FunnelやChuteで取り出します。タートルが直接搬出する面は塞がないでください。

推奨順序:

1. タートル後方に通常チェストを置く。
2. チェストの別面からFunnelまたはChuteを接続する。
3. BeltやItem Vaultへ送る。
4. 搬出速度が採掘速度を上回ることを確認する。
5. 最終倉庫が満杯になった時、ドックのチェストにも空きが残る設計にする。

搬出先が満杯でもアイテムを地面へ捨てず、`waiting_output` で停止します。

## 複数ワーカーを置く場合

- ワーカーごとに搬出チェストと燃料チェストを専用化します。
- ワーカー名は `Miner-A`, `Miner-B` のように重複させません。
- すべて同じネットワークキーを使います。
- 採掘直方体を重ねません。
- 帰還経路が他ワーカーのドックやCreate設備を横切らないようにします。
- 可能ならホーム間を3ブロック以上離し、誤って隣のチェストを使わない配置にします。

## 配置完了チェック

次がすべて「はい」ならプログラム導入へ進みます。

- [ ] タートルは採掘方向を向いている
- [ ] 搬出チェストは真後ろ1ブロック
- [ ] 燃料チェストは真上1ブロック
- [ ] タートルにDiamond PickaxeとWireless Modemの両方が付いている
- [ ] コントローラにWireless Modemが直接接触している
- [ ] 採掘体積に壊したくない設備がない
- [ ] チャンクをロードし続ける方法を確保している
- [ ] 搬出チェストに空きがある
- [ ] 燃料チェストに燃料以外が入っていない
