# 02. 建築と配置

## ドック上面

![タートルの後ろに搬出、右に封鎖材チェストを置く採掘ドック上面図](images/base-layout-top.svg)

1マスは1ブロックです。タートルの正面を採掘方向へ向けます。後ろに搬出チェスト、右に封鎖材チェストを置きます。封鎖材側はセットアップで左へ変更できます。

SVG内のブロックは75ピクセル単位の整数グリッドへ配置し、ブロック境界とマス目の線が一致するよう修正しています。

## ドック側面

![タートルの後ろの搬出チェストと真上の燃料チェストを示す採掘ドック側面図](images/dock-side.svg)

燃料チェストはタートルの真上です。搬出チェストは真後ろで、タートルが帰還後に180度回転して投入します。側面図は140ピクセルを1ブロックとして、全正方形を隙間なく接続しています。

## 採掘方向

- 幅 `W`: ドックから見て右方向
- 長さ `L`: 正面方向
- 深さ `D`: 下方向
- 最初の採掘セル: タートル正面1ブロック

通常の経路は次の蛇行です。

![正面の長さ方向から蛇行を始め、層末尾で1ブロック下降する通常採掘経路](images/quarry-path.svg)

チャンクマスクを使う場合はチャンクごとに内部蛇行し、DFSで隣接チャンクへ移動します。

![入口を保護し、中央チャンクを除外して周囲の許可チャンクを結ぶ経路例](images/chunk-mask.svg)

## GPSホスト

![高さを変えた4基のGPSホストで採掘域を囲む立体配置例](images/gps-layout.svg)

4台以上を5〜10ブロック程度の立体範囲へ分散します。全ホストを同じ常時ロード領域へ入れると管理しやすくなります。モデムの通信距離、ディメンション、高度、遮蔽条件はModpack設定に依存します。

## 設置後の確認

1. タートル正面に最低1ブロックの空間がある
2. 搬出チェストに空きがある
3. 燃料チェストに燃料だけが入っている
4. 封鎖材チェストに許可済み固体ブロックだけが入っている
5. ワーカーとコントローラーの無線モデムが有効
6. GPS使用時は4台以上が起動し、採掘地点で `gps locate` が成功する
