マニュアル / 建築と GPS

P1 / 初心者向け

建築と GPS を迷わず組む

GPS は任意ですが、world chunk、絶対 BOTTOM Y、world queue の重複検査、電源断後の移動判定を使うなら必要です。最低 4 台を同一平面に置かず、高さと座標を記録してください。

座標の読み方

ドックを原点にする座標軸

−Y（深さ）

幅 W は右（+X）、長さ L は前（+Z）、深さ D は下（-Y）。ホームは (0,0,0)。GPS world の値は dimension が変わると別空間です。

テキスト代替：図の左下がホーム。横方向右が +X、縦方向前が +Z、紙面の下方向が -Y。

GPS 塔：4 ホストの最低構成

GPS の距離測定に使われるのは Computer 本体ではなく、各ホストの Wireless Modem block の座標です。4 台を異なる高さ・四方向へ分散し、同一 dimension で、採掘地点まで通信できる範囲とロード状態を確保します。

高さをずらした 4 台（座標は例）

M1
GPS-A(100, 72, 100)
M2
GPS-B(100, 84, 132)
M3
GPS-C(132, 96, 100)
M4
GPS-D(132, 64, 132)

テキスト代替：左から M1〜M4。Y は 72、84、96、64 と異なり、X/Z も二方向へ分散。数字はワールド座標の記録例で、実際の値に置き換えます。

同一平面 4 台は避ける。 高さ・四方向が偏ると測位の幾何が悪くなります。GPS host を置いたチャンクと採掘地点がロードされている必要がありますが、そのロード状態の取得・自動化は CC Miner の責務ではありません。

各 host の起動手順

  1. Wireless Modem を Computer の隣接面に接続し、電源を入れます。ラベルを GPS-A〜D など固有名にします。
  2. 各 Computer で gps host を実行します。画面を閉じず、サーバー再起動後も起動できる startup 手順を用意します。
  3. モデム block の X/Y/Z、dimension、ホスト名を表に控えます。Computer の座標ではありません。
  4. worker の GPS 設定を enabled にし、required を選ぶ場合は fix timeout と fallback 方針を確認します。

worker の GPS CAL

  1. ドックでタートルの正面 1 ブロックを空け、搬出・燃料・seal・torch のチェストを動かせる状態にします。
  2. controller で worker を選択し、GPS CAL（または ccm calibrate <id>）を実行します。
  3. タートルが正面へ 1 ブロック進み、戻ります。GPS は向きを直接測れないため、この往復から +Z と home pose を保存します。
  4. fix、home 座標、向き、calibrated 表示を確認して小さな world job を preview します。
正面が塞がっていると CAL は開始しない。 物理操作が途中、fix 不能、旋回中の電源断は自動解決せず recovery wizard へ進みます。

GPS が失敗したときの初心者向け切分け

症状確認する順番安全な次の操作
4 台未満／fix なし各 host の gps host、Wireless Modem、電源、同一 dimension、遮蔽、距離。GPS 必須なら開始・帰還・復帰を押さず、host を起動して再試行。
校正だけ失敗正面 1 ブロック、タートルの向き、ドック座標、host のモデム座標。タートルを手で動かさず、wizard の案内でドックへ戻し再 CAL。
Boot GPS mismatch / driftドックを移設していないか、手動移動がないか、host 座標が変わっていないか。元のドックで REHOME RESET（job 消去）または job を ABORT して新ドックで校正。
採掘中に fix timeouthost と採掘チャンクのロード、通信距離、dimension、サーバー設定。GPS required は停止維持。任意設定は local にフォールバックするが world queue は使わない。
targetY が拒否calibrated home Y と入力した targetY。targetY は homeY 以下であること。depth = homeY - targetY + 1 を計算し、world queue で再入力。

GPS を使わない場合

worker は相対 chunk と入力した local depth で動きます。異なるドック間の相対範囲の重複を比較できず、world queue、world grid、絶対 BOTTOM Y、GPS による電源断移動判定は使えません。手動復旧用に最後の home pose とドック方向を紙などへ記録します。
