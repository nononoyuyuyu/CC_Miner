API と環境依存を確認する

実装・試験で参照する一次資料をまとめます。CC Miner の source、manifest.lua、installer、offline bundle が配布仕様の正本です。

Modpack／server 依存

  • 対象は Minecraft 1.18.2、CC: Restitched / CC:Tweaked 1.100.x 系を想定。
  • GPS 通信距離、host と採掘地点の chunk load、dimension、遮蔽はサーバー設定。
  • HTTP 許可と URL scope、燃料値、追加 fluid／inventory、speaker 音源、Wired Modem 名は環境依存。
  • torch、seal 材、protected block の item ID と recipe は Modpack ごとに確認。
  • チャンクロード状態の取得・表示・自動化、chunk loader の設置は CC Miner の対象外。

仕様の境界

位置

GPS は位置を返しますが向きを直接返しません。ドックの 1 block 往復で home pose を校正します。

安全

未知の block/fluid を安全とは仮定せず、preflight、protected list、小さな受入 job を使います。

通信

ACK/status の retry は通信の再送制御です。外部チェストや仕分け機の exactly-once を保証しません。

データ

state.db が正本。journal、history、report は補助・要約であり完全な監査ログではありません。

リポジトリ内の正本

CC Miner V4.0.0 は schema 4 として、runtime は src/ccminer/、配布一覧は manifest.lua と install.lua、生成物は dist/ccminer-offline-worker.lua／dist/ccminer-offline-controller.lua／dist/ccminer-offline-gps.lua と各 ccminer-offline-{role}.parts/、互換 dispatcher dist/ccminer-offline.lua（worker／controller／gps 引数）も正本にします。role loader の update は既存 config.role が一致する場合だけ実行し、online update-low-space の marker は version/role/next/phase と .tmp／.bak fallback を持ちます。ドキュメント入口はこの docs/index.html。生成物を直接編集せず、source を更新して bundle を再生成します。

公開 URL は nononoyuyuyu/CC_Miner の範囲に限定します。
