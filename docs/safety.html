手順書 / 安全のために

安全のために

CC Minerは、続けてよいか分からないときに止まるよう作られています。止まることは故障とは限りません。原因を確認せず、手で動かしたり記録を消したりしないでください。

してはいけないこと

  • 採掘中のタートルを壊して置き直す
  • タートルを押す、回す、テレポートさせる
  • 作業中に置き場やチェストを移す
  • エラーのまま state.db や journal を消す
  • 更新に失敗したとき、古い /ccminer を先に消す
  • 意味が分からないままREHOME RESETを実行する

水と溶岩

設定動きおすすめ
ignore水を無視して続ける安全を確認済みの場所だけ
stop見つけた場所で止まる初回
seal穴埋め材でふさぐ材料と動作を試した後

連続して大量に穴埋めしそうなときは上限で止まります。上限を大きくする前に、Modで追加された液体やブロックの判定を確認してください。

たいまつ

たいまつは敵が湧きにくくなる間隔で置きますが、必要な明るさはゲームの版やMod設定で変わります。最初はSAFEの間隔で実際の明るさを確認します。

一番下の高さ

GPSを使う作業では、BOTTOM Yへ「最後に掘りたいワールドの高さ」を入れます。ホームより上や、タートルに許した最大深さより下は開始できません。

例：置き場の高さがY=64で、BOTTOM YをY=12にすると、64から12までを含むため深さは53ブロックです。

チャンクの読み込み

CC Minerは、チャンクが読み込まれているかを調べたり、チャンクを読み込んだままにしたりできません。読み込まれていない場所へ入っても記録を失いにくい作りですが、サーバーやModのチャンクローダーが必要な場合は、管理者の説明に従ってください。

遠隔コンソールを使うとき

初期設定ではOFFです。使う必要がない限り、そのままにしてください。CCの rednet は暗号化されない無線なので、パスワードのように秘密を守る仕組みではありません。

  1. 採掘を停止する

    管理画面からRETURN HOMEまたはABORTを選び、タートルがドックで home になったことを確認します。

  2. controller pinを確認する

    管理用コンピューターで id と入力し、その番号をworkerの controllerId に入れます。0 のままでは有効化できません。

  3. 短時間だけ使う

    管理用コンピューターで ccm remote 12 を実行し、必要な読み取りだけを行います。終わるときは必ず exit を入力します。

  4. 危険な許可を増やさない

    allowShellは別確認のある上級設定です。削除や設定変更を含むシェルを許可するので、通常はOFFにします。文字入力を待つ対話型プログラムには対応しません。

残しておくファイル

  • /ccminer/config.db：設定
  • /ccminer/data/state.db：今の作業と位置
  • .bak：ひとつ前の控え
  • journal：細かな作業記録
  • logs：エラーや動作の記録

異常が起きたときは、これらを消す前にコピーします。
