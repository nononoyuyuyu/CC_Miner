管理画面

管理用コンピューターでは、採掘タートルの状態を見て、採掘の開始、停止、再開を指示します。普段は ccm dashboard だけ覚えれば十分です。

画面を開く

ccm dashboard

タッチできるモニターがあれば指で選べます。端末だけの場合は、矢印キー、Enter、Escを使います。

状態の意味

表示日本語の意味すること
idle待機中新しい採掘を始められます。
working採掘中手で触らず見守ります。
paused一時停止原因を確認してRESUMEで続けます。
returning / service置き場へ帰還・補給中通路とチェストを空けます。
waiting_fuel燃料待ち上面の燃料チェストへ補給します。
waiting_output搬出待ち背面の搬出チェストを空けます。
waiting_torchたいまつ待ち左面のたいまつチェストへ補給します。
waiting_seal穴埋め材待ち右面の穴埋め材チェストへ補給します。
blocked安全のため停止表示された理由を確認します。
complete完了結果を確認して次の作業を作れます。

よく使うボタン

NEW JOB

新しい採掘作業を作ります。

RESUME

一時停止した作業を、安全確認後に続けます。

STOP

すぐ停止、行末、層末、帰還、中止から選びます。

MORE

毎回は使わない設定や確認を開きます。REPORT、RECOVERY、GROUPS、GPSなどはここにあります。

ITEMS

MOREの中にあります。採掘タートルが今持っている物を一覧で見て、自動で捨てる候補をタッチして選びます。

REMOTE

採掘タートルの遠隔コンソールを使うコマンドを表示します。文字入力は管理用コンピューター本体で行います。

見やすさ：V4はモニターだけ明るい色へ調整します。通常の操作ボタンは明るい青地に白文字、選択中は黄色地に黒文字です。文字の左右には色付きの余白があり、十分な高さがあるモニターでは上下のボタンの間にも黒い空白行を入れます。更新後も暗い場合は、管理用コンピューターとモニターを再起動してください。

困ったときに使うコマンド

コマンド何を確認するか
ccm discover採掘タートルを探し直す
ccm status今の状態を文字で見る
ccm report今回と前回の結果を見る
ccm doctor設定、無線、GPS、燃料などをまとめて点検する
ccm logs直前の記録を見る

採掘タートルの遠隔コンソール

REMOTEボタンは、入力するコマンドを画面下へ表示します。モニターへ文字は入力できないため、管理用コンピューター本体の端末で次を入力します。

ccm remote 12

12は採掘タートルの番号へ置き換えます。新規セットアップでは、同じ合言葉のコントローラーから安全な確認コマンドだけを使えます。既存環境を更新した場合は、ワーカーでセットアップをやり直して有効にします。先に遠隔コンソールの安全設定を読み、採掘タートルをドックへ戻してください。

画面を閉じたいとき

まず Esc または画面の戻る操作を使います。最新版では採掘タートルもCtrlとTを長押しすると終了できますが、採掘中は先に管理画面から停止や帰還を指示してください。
