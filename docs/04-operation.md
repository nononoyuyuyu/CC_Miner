# 4. 実際の操作

## コントローラ画面

コントローラは起動時に自動でダッシュボードを開きます。閉じた場合は次で再表示します。

```text
ccm dashboard
```

上下キーでワーカーを選択します。

| キー | 操作 |
|---|---|
| `D` | ワーカーを再検出 |
| `N` | 新規クアリー開始 |
| `P` | 現在位置で一時停止 |
| `R` | 一時停止・待機・解除可能なブロックから再開 |
| `H` | ホームへ帰還し、搬出・補給後にホームで一時停止 |
| `S` | 手動サービス。帰還、搬出、補給後にホームで一時停止 |
| `X` | ジョブを中止しホームへ帰還。再開不可 |
| `C` | 完了・中止済みのジョブ記録を消去 |
| `I` / Enter | 選択中ワーカーの詳細 |
| `G` | 物理復旧後の座標リセット。危険操作 |
| `Q` | ダッシュボードを閉じる |

## 新規ジョブを開始する

1. `D` を押し、対象ワーカーが `idle`, `complete`, `aborted` のいずれかでオンライン表示されることを確認します。
2. 上下キーで対象を選びます。
3. `N` を押します。
4. 幅 `W`、長さ `L`、深さ `D` を整数で入力します。
5. 表示された総ブロック数と方向を確認します。
6. `Start this job` に `Y` と答えます。

ジョブ開始直後、ワーカーは必ずホームで次を実行します。

1. 搬出チェストの存在確認
2. インベントリの全搬出
3. 燃料チェストの存在確認
4. 燃料目標まで補給
5. 正面1ブロック目から採掘開始

したがって、チェストの誤配置や燃料不足は、採掘範囲へ出る前に検出されます。

## 寸法入力の例

```text
Width  = 8
Length = 32
Depth  = 16
```

この場合、タートル右方向へ8列、前方へ32ブロック、同じ高さから下へ16層、合計4096セルです。

深さは「現在位置からさらに16ブロック下」ではありません。同じ高さが1層目なので、最下層のY差は `-15` です。

## 自動搬出・補給中の表示

| Phase | 処理 |
|---|---|
| `service_requested` | 帰還準備 |
| `returning` | ホームへ移動中 |
| `unloading` | 後方チェストへ搬出中 |
| `refueling` | 上方チェストから補給中 |
| `going_back` | チェックポイントへ復帰中 |
| `mining` | 採掘中 |

自動サービスはジョブを失いません。ホームへ戻っても、画面上の進捗とチェックポイントは保持されます。

## 一時停止と帰還の違い

### Pause

`P` または `ccm pause <ID>` は、その時点の安全な命令境界で停止します。採掘地点に留まる場合があります。保守のためタートルへ直接触る用途には使わず、短い運用停止に使います。

### Recall

`H` または `ccm recall <ID>` は、現在地点を保存してホームへ戻り、搬出と補給を行った後、ホームで停止します。再度 `R` を押すと、元の地点へ戻ってジョブを継続します。

機械を止めてサーバを再起動する、周囲を整備する、燃料箱を交換する場合はPauseよりRecallを使います。

### Service

`S` はRecallと似ていますが、ジョブがなくてもホームの搬出・補給を実行できます。手動保守に使います。

### Abort

`X` はホームへ戻りますが、採掘地点へ復帰するためのチェックポイントを破棄します。中止後の同じジョブは再開できません。

## 完了後

採掘が完了するとワーカーはホームへ戻り、最後の搬出・補給を行い、`complete` になります。

- 進捗や完了理由を残したまま、別の新規ジョブを開始できます。
- 記録を明示的に消す場合は `C` を押します。
- Bedrockを下向き移動で検出した場合、予定深度前でも `bedrock_reached` として正常完了します。

## コマンドライン操作

IDが分かっている場合、ダッシュボードを開かずに操作できます。

```text
ccm discover
ccm start 12 8 32 16
ccm pause 12
ccm resume 12
ccm recall 12
ccm service 12
ccm abort 12
ccm clear 12
```

物理復旧後の座標リセットだけは、確認語が必要です。

```text
ccm rehome 12 RESET
```

`rehome` は現在のジョブを消去します。タートルをホームへ物理的に戻し、正面を採掘方向へ合わせた後だけ実行してください。

通信不能時はワーカー端末で `Ctrl+T` を長押しし、`ccm rehome RESET`、`reboot` の順に実行できます。

## 燃料と搬出の運用

- 燃料チェストには常に十分な燃料を残します。
- 搬出チェストの下流倉庫も含め、満杯にならないようにします。
- `waiting_fuel` または `waiting_output` は故障ではなく、安全待機です。
- 原因を直した後、コントローラで `R` を押します。

## 複数ワーカー

1台のコントローラで複数IDを一覧表示します。各ワーカーへ別のジョブを送れます。

- 同時採掘する範囲を重ねない
- 同じブロックを両側から掘らせない
- 搬出物流の処理能力を合計採掘量より大きくする
- すべてのチャンクをロードする
