# 04. 操作方法

## ダッシュボード

`ccm dashboard` で開きます。接続済みAdvanced Monitorとコンピューター画面へ同時に描画されます。

ワーカー行をタッチ／クリックして選択し、画面下部のボタンを使います。

| ボタン | 動作 |
|---|---|
| DISCOVER | ワーカーを再探索 |
| NEW JOB | 寸法入力とチャンクマスク |
| GPS CAL | ドックで正面へ1ブロック往復してGPS校正 |
| INFO | GPS、燃料、封鎖材、ジョブ、統計を表示 |
| PAUSE / RESUME | 現在位置と経路を保持して停止／再開 |
| RECALL | ドックへ戻り、チェックポイントを保持して停止 |
| SERVICE | 搬出・燃料・封鎖材補給後に停止 |
| ABORT | ドックへ戻ってジョブを中止 |
| CLEAR | 完了／中止済みジョブ記録を消去 |
| REHOME | 物理回収後の座標・ジョブ初期化 |

キーボードショートカットも残しています。`D/N/P/R/H/S/X/C/I/G/L/Q` と上下キーを使用できます。

## 新規ジョブ

### 寸法画面

幅、長さ、深さの行を選択し、画面内キーパッドまたはキーボードで値を入力します。`+` と `-` でも調整できます。

- **START ALL**: チャンク除外なしで高速蛇行経路を開始
- **CHUNK MASK**: 個別チャンク選択へ進む

### チャンクマスク

各行をタッチすると `MINE` と `EXCLUDE` が切り替わります。入口チャンクは `ENTRY` と表示され、除外できません。

GPS校正済みワーカーはワールドチャンク座標を表示します。未校正ワーカーはドック原点基準の相対16×16区画を表示します。

開始時に許可チャンクの連結性を検査します。除外帯によって奥側が分断されるなど、入口から到達できないチャンクがある場合はエラーになります。

## GPS校正

1. 4台以上のGPSホストを起動します。
2. タートルをドック `(0,0,0)` に置き、採掘方向を向けます。
3. 正面1ブロックを空けます。
4. タートルに最低2燃料を入れます。
5. コントローラーで **GPS CAL** → **YES** を押します。

タートルは現在位置を取得し、正面へ1ブロック進んでもう一度取得し、後退してドックへ戻ります。2点の差から正面ベクトルを保存します。

## 溶岩封鎖

`lavaMode=seal` の場合、進行方向に溶岩を検知すると封鎖材を設置し、固体化した進行セルを掘って移動します。封鎖材残量が `sealReserve` 以下になると補給へ戻ります。

封鎖材が完全に無い状態で溶岩へ到達した場合も、その場で無理に進まず補給経路へ切り替えます。帰還経路上で新たな溶岩が出現し、封鎖できない場合は安全停止します。

## 状態確認

```text
ccm status
ccm logs
ccm discover
ccm gps <id>
```

`ccm gps <id>` は現在のGPS fixと校正座標の一致を確認します。
