手順書 / 速さと帰還

速さと帰還

タートルが1ブロック動く速さには、ゲーム側の上限があります。大きく速くするには、動きそのものを無理に速めるより、不要な帰還や待ち時間を減らします。

CCそのものの速度

CC:TweakedやCC: Restitchedのタートルは、ゲームの設定とサーバーの処理速度に従って動きます。通常のプログラムから、動作間隔を上限より短くすることはできません。

  • サーバーが重いと、タートルも遅く見えます。
  • 表示用モニターを大きくし過ぎると、画面更新が重くなることがあります。
  • GPS確認、保存、ブロック確認を全部なくすと速くなりますが、事故時に戻れなくなるため行いません。

帰還回数を減らす

  1. REPORTを見る

    帰還理由が燃料、持ち物、たいまつ、穴埋め材のどれかを確認します。

  2. 原因だけを直す

    燃料なら燃料を増やし、持ち物なら不要な石の処分や空き枠を見直します。すべての安全余裕を一度に減らさないでください。

  3. BALANCEDを試す

    SAFEで1回成功した範囲だけ、BALANCEDに変えて比べます。

  4. 1回分の結果を比べる

    所要時間、帰還回数、燃料、停止回数を見ます。エラーが増えたら元へ戻します。

補給後の無駄な往復を減らす

帰還前に、掘っていた場所と向きを再開地点として保存します。補給後は採掘範囲の一番奥まで行って折り返さず、許可されたチャンクの中で再開地点までの短い道を選びます。

補給後は保存した場所へ直接戻る

採掘中場所と向きを保存
置き場搬出と補給
再開保存した場所へ戻る
安全な通路の中から短い道を選ぶ

採掘場所から置き場へ帰り、補給後は保存した再開地点へ戻ります。範囲の端まで行って折り返す動きはしません。

安全にできる改善

改善効果注意
掘った石を穴埋めに再利用穴埋め材の補給を減らす残す石の数を0にしない
余った普通の石を処分持ち物が満杯になるまで長く掘れる最初はKEEP_ALLで確認
たいまつの間隔を少し広げるたいまつ補給と設置の時間を減らす敵が湧かない明るさをゲーム内で確認
複数台へ範囲を分ける全体の終了時間を短くするGPSと専用置き場が必要
モニターを必要な大きさにする画面更新の負担を減らす操作に必要な表示は残す

速くするために消してはいけないもの

  • 移動前後の保存
  • 水・溶岩・落下するブロックの確認
  • 燃料を残して帰れるかの計算
  • GPSを必須にしたときの位置確認
  • 複数台の採掘範囲が重ならないかの確認
