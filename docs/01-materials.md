# 01. 必要資材

## 最小構成

| 用途 | 数量 | 内容 |
|---|---:|---|
| 採掘 | 1以上 | Advanced Mining Turtle |
| ワーカー通信 | ワーカーごとに1 | Wireless Modem |
| 管理 | 1 | Advanced Computer |
| 管理通信 | 1 | Wireless Modem |
| 搬出 | ワーカーごとに1 | Chest / Barrel等 |
| 燃料 | ワーカーごとに1 | Chest / Barrel等 |
| 溶岩封鎖材 | ワーカーごとに1 | Chest / Barrel等 |
| 封鎖ブロック | 継続補給 | Cobblestone等の設定済み固体ブロック |

標準の封鎖材許可リストは Cobblestone、Cobbled Deepslate、Stone、Netherrack、Dirt です。燃焼・落下・重力・液体・貴重ブロックは使わないでください。

## タッチ操作を使う構成

| 用途 | 数量 | 内容 |
|---|---:|---|
| 表示・タッチ | 1以上 | Advanced Monitor |

端末画面でもマウスクリックできます。モニターは1台以上接続でき、接続された各モニターへ同じ操作画面を描画します。小さすぎるモニターではチャンク一覧の表示行数が減るため、複数ブロックの画面を推奨します。

## GPS完全構成

| 用途 | 数量 | 内容 |
|---|---:|---|
| GPSホスト | 4以上 | Computer / Advanced Computer |
| GPS通信 | ホストごとに1 | Wireless Modem |
| 常時ロード | 必要数 | ModpackのChunk Loader等 |

![高さを変えた4基のGPSホストで採掘域を囲む立体配置例](images/gps-layout.svg)

4台を同一平面へ並べず、高さを変えて立体的に配置します。各ホストへ入力する座標はコンピューター本体ではなく、距離測定に使われる無線モデムブロックの座標です。

## ドック占有範囲

ワーカー1台につき、少なくとも次の空間を確保します。

- タートル本体: 1ブロック
- 正面: 採掘入口
- 後ろ: 搬出チェスト
- 上: 燃料チェスト
- 右（または設定した左）: 封鎖材チェスト
- GPS校正用: 正面1ブロックを一時的に空けられること
