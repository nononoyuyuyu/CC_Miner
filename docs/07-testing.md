# 07. 検証

## 一括検査

```bash
python3 tools/check.py
```

検査内容:

1. 全Luaファイルの構文読み込み
2. 通常蛇行経路が全セルを重複なく隣接移動すること
3. チャンクカタログ、除外、連結性拒否、DFS往復、内部蛇行
4. 負座標を含むGPS座標変換とチャンク計算
5. 保留移動のGPS前後判定
6. 状態ファイルの原子的入れ替えと `.bak` 復旧
7. manifest、オンラインインストーラー、オフラインビルダーの収録一致
8. タッチ・GPS・溶岩封鎖・チャンク除外の必須実装マーカー
9. Markdown相対リンク
10. SVGの色付きブロックが宣言グリッドへ一致すること
11. 分割オフライン配布物の連番・各ファイルサイズ・再結合後Lua構文

## 実機受け入れ試験

### タッチ

- モニターでワーカー行を選択できる
- 数字キーパッドでW/L/Dを変更できる
- チャンク行をタッチして除外状態を切り替えられる
- 確認画面のYES/NOが動作する

### GPS

- 4ホストでGPS CALが成功する
- `ccm gps <id>` が校正座標と一致する
- 前進直後に強制終了し、再起動で移動前／後を自動判定する
- 旋回中の強制終了はREHOMEを要求する

### 溶岩

安全な試験区画で前方・上・下の溶岩を用意し、固体ブロックを設置してから進むこと、残量低下で補給へ戻ることを確認します。

### チャンク除外

- GPSありでワールドチャンク座標が表示される
- GPSなしで相対区画が表示される
- 中央チャンクを除外して周囲が連結しているジョブは開始できる
- 横一列を除外して奥が分断されるジョブは拒否される
- 補給帰還時も除外チャンクへ入らない
