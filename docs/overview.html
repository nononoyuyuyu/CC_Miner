しくみを知る

このページは、手順どおりに使えるようになった後の補足です。初回の建築や採掘に必要な内容は、前のページだけで足ります。

3つの役目

採掘タートル

掘る、動く、たいまつを置く、穴をふさぐ、荷物を運ぶ役目です。

管理用コンピューター

採掘する場所を決め、開始や停止の指示を送り、結果を表示します。

GPS用コンピューター

ワールドのどこにいるかを調べるための目印です。4台以上で位置を計算します。

動く前に保存する理由

タートルが「次に何をするか」を保存してから動くことで、直後に電源が切れても、どこまで進んだ可能性があるかを調べられます。再起動後に判断できないときは、勝手にもう一度動かず停止します。

採掘の道と帰還の道

採掘するときは、すべての場所を漏れなく通れる順番を使います。補給で戻るときは、保存した再開地点と置き場の間で、通ってよいチャンクだけを使った短い道を選びます。

高さの指定

GPSなしでは「ここから下へ何ブロック」という深さで指定します。GPSありでは「ワールドのY座標がいくつまで」という一番下の高さでも指定できます。

このプログラムだけではできないこと

  • チャンクが読み込まれているかの確認
  • チャンクを自動で読み込んだままにすること
  • ゲーム管理者の代わりに保護範囲や権限を変えること
  • 人が手で掘っている場所との重なりを見つけること
  • 合言葉を強い暗号として守ること
画面に出る少し難しい言葉
worker
採掘タートル。
controller
管理用コンピューター。
job
1回の採掘作業。
preflight
開始前チェック。
checkpoint
再開地点。
dock / bay
タートルの置き場。
queue
作業の順番待ち。
lease
同じ場所を2台で使わないための予約。
