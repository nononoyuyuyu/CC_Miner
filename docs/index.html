手順書 / はじめに

CC Minerを使い始める

この手順書は、設計を学ぶための資料ではありません。採掘タートルを初めて使う人が、書いてある順番どおりに進めて、安全に採掘を始めるための説明書です。

どこから読みますか

初めて使う必要な物、置き方、プログラムの入れ方、最初の採掘までを一続きで説明します。今、エラーで止まっている表示された言葉を探して、上から順に確認します。タートルを手で動かす前に読んでください。設定の意味を知りたい画面や設定に出る項目を、日本語の説明とおすすめ値で確認します。

最初に覚える名前は4つだけ

採掘タートル

実際に動いて掘る機械です。画面では worker と表示されることがあります。

管理用コンピューター

採掘する場所を決め、開始や停止を指示します。画面では controller と表示されることがあります。

置き場

タートルが出発し、燃料補給や荷物の搬出のために戻る場所です。画面では dock や bay と表示されます。

再開地点

補給のために戻る前に保存する場所です。画面では checkpoint と表示されることがあります。

大切：採掘中のタートルを、手で壊したり、押したり、向きを変えたりしないでください。位置が分からなくなったときは、安全のために止まります。

初めて使うときの順番

  1. 必要な物を集める

    採掘タートル、管理用コンピューター、無線モデム、燃料、チェストを用意します。

  2. 先にブロックを置く

    タートルの置き場と管理用コンピューターを作ります。GPSを使うなら、このときGPS用コンピューターも置きます。

  3. プログラムを入れる

    置き終わってから、採掘タートルと管理用コンピューターに、それぞれのプログラムを入れます。

  4. 小さな範囲で試す

    最初は1チャンク、深さ8ブロック程度にします。正しく戻り、荷物を出せることを確認してから広げます。

すぐ始めたい方：まず動かす：最小構成の手順へ進んでください。説明を飛ばさず、そのページを上から順に実行します。
