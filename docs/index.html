V4.0.0 / schema 4

CC Miner を安全に始める

CC Miner V4 は Advanced Mining Turtle と Advanced Computer で、チャンク単位の遠隔クアリーを復旧可能な状態機械として運転します。この入口から、初回設置、GPS 校正、ジョブ作成、停止・復旧までを順に確認できます。

初めての方

導入・更新 → 建築と GPS → 初回ジョブの順で進めます。

今、停止した方

タートルを動かさず、復旧 wizardと waiting_* の切分けを確認します。

仕様を確認したい方

P0 / P1 / P2、group / discard、絶対 BOTTOM Yを参照します。

最短の初回手順

  1. 役割を導入する。 worker、controller、必要なら GPS host を同じネットワークキーで設定します。HTTP が使えない場合は offline bundle を使います。
  2. ドックを小さく作る。 後ろに搬出、上に燃料、seal=右、torch=左の専用チェストを置き、入口を空けます。
  3. GPS を使うなら CAL。 4 台以上のホストを異なる高さに置き、モデム座標を登録します。正面を 1 ブロック空け、GPS CAL の往復を完了します。
  4. 小さい job を preview。 幅・長さ・深さ、SAFE/BALANCED/TURBO、chunk grid、液体・照明を入力し、preflight の fatal がゼロであることを確認します。
  5. 運転中は境界で止める。 PAUSE / STOP / RECALL を使い、手動でタートルを押したり回したりしません。完了後は report と補給結果を確認します。
対象外の境界。 CC Miner はチャンクロード状態を取得・表示・自動化しません。必要なロード範囲はサーバー／Modpack 管理者が用意します。管理者権限、認証基盤、強い暗号化も提供しません。

よく使うコマンド

ccm dashboard
ccm discover
ccm status
ccm report
ccm doctor
ccm logs
ccm start <id> <width> <length> <depth>
ccm pause|resume|recall|service|abort|clear <id>
ccm dock register <id> <x> <y> <z> [facing] [maxDepth]
ccm bay register <id> <x> <y> <z> [facing] [maxDepth]
ccm group register <id> <workerIds comma> [name dock bay mode partition workerBayMap workerDockMap]
ccm group list|show|start|pause|resume|return|service|abort|clear|reassign <id>
ccm gps <id>
ccm calibrate <id>
ccm rehome <id> RESET

CLI の start は簡易入口です。chunk grid、profile、queue、段階停止、history/report は dashboard から操作します。
